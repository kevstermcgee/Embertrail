# Embertrail

An original 32-course platforming adventure built with BlueEngine. Guide Mote, a lantern spirit, through eight worlds to recover the dawn.

[Play Embertrail](https://kevstermcgee.github.io/Embertrail/embertrail/)

Move with arrows or WASD, jump with Space or Up, and run with Shift. Hold Up for higher jumps. Esc pauses; K/L save and load. Touch controls and standard controllers are supported. Browser saves stay on this device, and a complete first load enables offline play.

[Game source and development guide](https://github.com/kevstermcgee/BlueEngine/tree/game/embertrail/games/embertrail). All characters, artwork, music and levels are original.

The release uses BlueEngine's public-source retrieval and clean reproduction gate. Deployment verifies every runtime file against the release manifest.
